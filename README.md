## 系統說明

`Node版本: >=20`

- 安裝： `pnpm install`
- 執行： `pnpm dev`

## 使用技術
- 框架： react

- 樣式： chakra-ui

- canvas套件： fabric

- pdf套件：jspdf、pdfjs

- 表單驗證： react-hook-form
